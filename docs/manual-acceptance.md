# 手动验收清单

## 启动与入口

- 运行应用后，macOS 顶部菜单栏出现历史粘贴板图标。
- 点击菜单栏图标后，弹出半透明玻璃质感面板。
- 点击面板外部或再次点击菜单栏图标，面板可以关闭。

## 文字历史

- 复制一段文字后，历史列表出现文字卡片。
- 连续复制相同文字，不会重复新增相同卡片。
- 点击整张文字卡片后，可以在其他 App 中按 Command+V 粘贴。
- 删除文字卡片后，该记录从列表中消失。

## 图片历史

- 复制一张图片后，历史列表出现图片缩略图卡片。
- 鼠标悬停在图片缩略图上，图片会适度放大预览，列表布局不跳动。
- 点击整张图片卡片后，可以在支持图片粘贴的 App 中按 Command+V 粘贴。
- 删除图片卡片后，该记录从列表中消失。

## 搜索与置顶

- 在搜索框输入文字关键词，只显示匹配的文字历史。
- 搜索无结果时显示“没有找到匹配内容”。
- 点击置顶按钮后，该卡片显示在普通卡片上方。
- 退出并重新启动应用后，置顶状态仍保留。

## 保存期限

- 保存期限可切换为 1 天、3 天、5 天。
- 过期且未置顶的历史会自动清理。
- 置顶历史不会因保存期限自动删除。

## 隐私控制

- 开启“暂停记录”后，再复制新内容不会新增历史。
- 关闭“暂停记录”后，复制新内容会继续新增历史。
- 点击“清空”后会出现二次确认。
- 确认清空后，所有文字和图片历史都被删除。

## 开机启动

- 开机启动开关可点击。
- 调试运行版本可能无法完成注册；正式 macOS App 包中需要再次确认。

## 稳定性

- 长文字卡片不会撑坏布局。
- 图片缩略图不会挤压底部设置区。
- 半透明玻璃背景下，文字和按钮仍清晰可读。
- 应用退出并重新启动后，历史、置顶和设置状态保持一致。
