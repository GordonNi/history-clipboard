# UI 与交互设计规范

## 设计目标

界面要简洁、直观、轻量。用户打开后应立刻知道最近复制了什么，并能快速搜索、置顶、删除或重新复制。

## 视觉风格

- 主色：淡蓝色。
- 辅助色：半透明白色、浅灰、深灰文字。
- 风格：干净、克制、工具型，并带轻量半透明液态玻璃质感。
- App 封面和应用图标使用淡蓝色液态玻璃风格，主体应表达剪贴板、历史卡片和本地工具属性。
- 面板背景、搜索框、历史卡片和底部栏优先使用 macOS 原生毛玻璃材质。
- 避免大面积装饰背景。
- 避免复杂渐变和过多阴影。
- 玻璃质感必须服务于可读性，不能让文字和按钮难以识别。

## 建议颜色

- 主色：`#7DB7E8`
- 主色浅背景：`#EEF7FF`
- 选中或 hover 背景：`#DCEFFF`
- 页面背景：`#F7FAFC`
- 卡片背景：`#FFFFFF`
- 玻璃叠色：淡蓝色低透明度叠加
- 主要文字：`#1F2933`
- 次要文字：`#6B7280`
- 分割线：`#E5E7EB`
- 删除危险色：`#D64545`

## 主面板布局

- 面板宽度建议 360 到 420 pt。
- 面板高度建议 520 到 640 pt。
- 顶部放搜索框和设置入口。
- 中间为历史列表。
- 底部可放暂停记录、保存期限等轻量设置。

## 历史卡片

- 卡片按时间降序排列。
- 置顶卡片显示在普通卡片前。
- 文字卡片显示最多数行摘要。
- 图片卡片显示缩略图。
- 图片缩略图使用固定高度，避免图片比例变化导致卡片布局大幅跳动。
- 鼠标悬停在图片缩略图上时可适度放大预览，但不能改变列表布局尺寸。
- 每张卡片显示复制时间。
- 每张卡片提供置顶和删除按钮。
- 点击卡片主体表示重新复制到剪贴板。

## 空状态

- 没有历史时显示简短提示，例如“还没有复制记录”。
- 搜索无结果时显示“没有找到匹配内容”。
- 暂停记录时要有明确但不干扰的状态提示。

## 交互规则

- 点击历史卡片后，不自动粘贴，只重新复制到系统剪贴板。
- 点击后可显示短暂反馈，例如“已复制”。
- 删除单条可直接删除。
- 清空全部需要二次确认。
- 保存期限使用 1 天、3 天、5 天的分段选择。
- 暂停记录使用开关。
- 清空全部历史需要二次确认。
- 开机启动使用开关，调试运行时如果系统不支持当前可执行文件注册，需要给出失败提示。

## 可访问性

- 按钮要有明确图标或文字。
- 重要操作不能只依赖颜色表达。
- 文字大小要适合普通 mac 用户阅读。
- 长文本不能撑坏布局。

## 设计约束

- 不做营销页。
- 不在工具面板里写长篇说明。
- 不使用复杂动画。
- 不让 UI 元素互相遮挡。
- 优先保证高频操作顺手。
