# 分阶段开发计划

## 推进原则

- 每次只推进一个小阶段。
- 每个阶段结束后更新当天开发日志。
- 每个阶段结束后至少做一次构建或手动验证。
- 新想法先写入待办，不直接扩大当前阶段。

## 阶段 1：项目治理结构

目标：创建项目文档、开发日志和代理工作说明。

交付：

- `docs/requirements.md`
- `docs/technical-architecture.md`
- `docs/design-guidelines.md`
- `docs/development-plan.md`
- `docs/quality-standards.md`
- `dev-logs/YYYY-MM-DD.md`
- `AGENTS.md`

验收：

- 文件结构存在。
- 文档内容覆盖需求、技术、设计、质量和执行步骤。
- 开发日志包含已完成、待办、问题、下一步。

## 阶段 2：项目初始化

目标：创建 Swift/macOS App 基础项目。

交付：

- 可用的 Swift Package macOS App 项目，可通过 Xcode 打开 `Package.swift`。
- 基础 App 可编译、可启动。

验收：

- 使用 Xcode 或命令行构建通过。
- 应用可以启动。
- 暂不接入剪贴板逻辑。

## 阶段 3：菜单栏应用骨架

目标：实现顶部菜单栏入口和基础弹出面板。

交付：

- 菜单栏图标。
- 点击图标弹出面板。
- 面板包含占位 UI。

验收：

- 启动后菜单栏可见图标。
- 点击图标能打开和关闭面板。

## 阶段 4：文字剪贴板监听

目标：先记录文字复制历史。

交付：

- 剪贴板变化监听。
- 文字历史临时列表。

验收：

- 复制文字后面板能显示新记录。
- 相同内容不会连续重复记录。

## 阶段 5：本地持久化

目标：让文字历史重启后仍保留。

交付：

- Core Data 数据模型。
- 历史新增、查询、删除基础能力。

验收：

- 退出重开应用后文字历史仍存在。

## 阶段 6：历史列表基础操作

目标：让历史可查看、复用、删除。

交付：

- 时间降序列表。
- 点击卡片重新复制。
- 单条删除。

验收：

- 用户能查看、复用、删除文字历史。

## 阶段 7：搜索与置顶

目标：提升查找和管理效率。

交付：

- 搜索框。
- 置顶和取消置顶。
- 置顶状态持久化。

验收：

- 搜索能过滤文字历史。
- 置顶内容显示在顶部。
- 重启后置顶状态仍存在。

## 阶段 8：保存期限

目标：实现 1/3/5 天自动清理。

交付：

- 保存期限设置。
- 过期清理逻辑。

验收：

- 未置顶内容按保存期限清理。
- 置顶内容不自动删除。

## 阶段 9：图片剪贴板支持

目标：支持图片历史。

交付：

- 图片读取。
- 图片本地保存。
- 图片缩略图展示。
- 点击图片历史重新复制。

验收：

- 图片可记录、查看、再次粘贴。

## 阶段 10：设置与隐私控制

目标：补齐基础控制项。

交付：

- 暂停记录开关。
- 清空全部历史。
- 开机启动开关。

验收：

- 设置项生效并持久化。
- 清空全部有二次确认。

## 阶段 11：UI 打磨与稳定性检查

目标：让第一版可稳定使用。

交付：

- 淡蓝色简洁界面。
- 空状态、长文本、图片缩略图、按钮状态优化。
- 主要流程验证记录。

验收：

- 主要流程稳定。
- 无明显 UI 错位。
- 文档和日志更新完整。

## 阶段 12：本地安装准备

目标：让已验收的第一版可以稳定安装到本机应用目录。

交付：

- 本地安装脚本。
- 安装、运行和验证说明。

验收：

- 打包脚本仍可成功生成 `dist/HistoryClipboard.app`。
- 安装脚本可把 App 复制到用户应用目录。
- 安装后的 App 可启动。
- 文档和日志更新完整。

## 阶段 13：GitHub 开源发布准备

目标：将完整源码按公开仓库规范安全发布到 GitHub。

交付：

- 项目首页 `README.md`。
- 开源许可证 `LICENSE`。
- 贡献指南 `CONTRIBUTING.md`。
- 安全政策 `SECURITY.md`。
- 完整且适合公开发布的 `.gitignore`。
- 初始化 Git 仓库并上传到公开 GitHub 仓库。

验收：

- 不包含密钥、个人路径、剪贴板数据或本机构建缓存。
- `swift build` 通过。
- GitHub 仓库可公开访问。
- README 能清楚说明功能、隐私、开发和打包方式。
- 文档和日志更新完整。
