# 历史粘贴板产品需求

## 项目目标

开发一个运行在 macOS 上的菜单栏历史粘贴板应用，帮助用户自动记录近期复制过的文字和图片，并在需要时快速查找、重新复制和管理。

## 目标用户

- 不熟悉复杂软件设置的普通 mac 用户。
- 经常需要在不同软件之间复制文字、截图或图片的用户。
- 希望近期剪贴板内容只保存在本机、不上传云端的用户。

## 第一版功能范围

- 菜单栏常驻入口。
- 自动记录复制的文字和图片。
- 历史记录按时间降序显示。
- 置顶重要历史内容。
- 删除单条历史内容。
- 搜索文字历史。
- 设置保存期限：1 天、3 天、5 天。
- 未置顶内容超过保存期限后自动清理。
- 置顶内容不自动清理，只能手动删除。
- 点击历史卡片后，将内容重新复制到系统剪贴板。
- 暂停记录开关。
- 清空全部历史。
- 可开关的开机自动启动。

## 暂不做事项

- 不做自动粘贴到当前 App，避免第一版申请辅助功能权限。
- 不记录复制的文件。
- 不做云同步。
- 不做多设备同步。
- 不做应用黑名单。
- 不做富文本格式保留。
- 不做网页来源、复制来源 App 记录。

## 核心使用流程

1. 用户启动应用。
2. 应用在 macOS 菜单栏显示图标。
3. 用户复制文字或图片。
4. 应用自动记录内容。
5. 用户点击菜单栏图标打开历史面板。
6. 用户搜索、置顶、删除或点击某条历史。
7. 点击历史后，该内容重新进入系统剪贴板。
8. 用户在目标软件中按 Command+V 粘贴。

## 验收标准

- 应用启动后可在菜单栏看到入口。
- 复制文字后，历史面板出现对应记录。
- 复制图片后，历史面板出现缩略图。
- 点击文字或图片历史后，可再次粘贴。
- 搜索能筛选文字历史。
- 置顶内容始终显示在普通内容上方。
- 删除和清空操作立即生效。
- 保存期限只清理未置顶内容。
- 应用退出重启后，历史、置顶状态和设置仍然保留。
